NeoMTP Privacy Policy

Effective date: August 17, 2026

NeoMTP is an independent project that began as a fork of OpenMTP. This policy describes how the NeoMTP application handles data.

Data collection

NeoMTP does not collect telemetry, analytics, usage data, or crash reports. It does not automatically send your files or diagnostic logs to remote services.

NeoMTP does not ask for personal information. It does not use cookies, third-party tracking tools, or third-party analytics.

Local data

The application stores settings and diagnostic logs locally on your Mac. These files remain under your control. Diagnostic logs are not uploaded automatically.

File transfers occur only between your Mac and the Android device that you select.

Network requests

NeoMTP can contact GitHub to check for application updates and to test the internet connection. These requests do not include your files, usage data, or diagnostic logs.

You can disable automatic update checks in the application settings.

Optional reports

If you choose to report a problem, you decide what information to include in the GitHub issue. GitHub handles any information that you submit there under its own policies.

Report problems at https://github.com/tstejl/neomtp/issues.

Changes to this policy

We may update this policy when the application or its data practices change. The date at the top of this page shows when this version took effect.

License and attribution

NeoMTP retains the factual attribution and license history of the original OpenMTP project. See the NeoMTP repository and its license files for details.
