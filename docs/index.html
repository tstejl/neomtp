NeoMTP

Android file transfer for macOS

Browse and transfer files between your Mac and an Android MTP device over USB.

NeoMTP began as a fork of OpenMTP and is now an independent project.

Latest version: NeoMTP

Built for local USB transfers

NeoMTP keeps file browsing and transfers on your Mac and connected Android device.

No account, remote service, telemetry, or analytics is required.

  • Apple Silicon and Intel Mac support
  • Android MTP device support
  • USB file browsing and transfer
  • Multiple-file transfers
  • Transfers for files larger than 4 GB
  • Drag and drop support
  • Grid and list views
  • Dark theme mode
  • Keyboard shortcuts
  • No telemetry or analytics
  • Open-source code and transparent releases
