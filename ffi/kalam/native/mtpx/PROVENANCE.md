# MTP file operations provenance

This package was extracted from
[`github.com/ganeshrvel/go-mtpx`](https://github.com/ganeshrvel/go-mtpx/tree/18f12db021cc4256396748dbd2996d15853d7033)
at commit `18f12db021cc4256396748dbd2996d15853d7033`.

OpenMTP copied only the production source files. The upstream tests require a
physical device and a pre-seeded directory. OpenMTP did not copy those tests.
It will replace them with isolated tests that manage their own data.

The upstream repository did not contain a license file at this commit. Do not
treat this package as MIT-licensed. Clarify its license or replace it before
public redistribution.
